一个按时间查看 agent 的屏幕，从侧边栏「时间线」进入。

每个 agent 一条时间条，左端是 agent 开始时间、右端是更新时间，所有时间条共用一条时间轴。时间条的文字靠右对齐（贴着更新时间一端），主标题是所属 workspace、次标题是 agent 标题；时间条有最小宽度，跨度太短时向左延展、右端仍对准更新时间；同一个 workspace 的 agent 使用同一种颜色，重新打开颜色不变。窗口默认以「今天」居中（1 天跨度正好覆盖当天），可以左右拖动平移，也可以滚轮缩放（以指针位置为锚点，`Shift+滚轮` 上下滚动轨道），越靠右的方框表示最近更新得越近。方框内标注状态文字与更新时间，运行中的 agent 最后一行显示实时输出的最新一行。方框按状态上下分区，运行中固定在最上面；点选方框可以看到完整时间、跨度、实时输出，并直接打开该 agent。窗口跨度可用 1 / 3 / 7 / 30 天快捷切换，`‹` / `›` 平移，点「今天」回到当天。

节点上的时间是 agent 最近一次状态变更或用户消息的时间；归档 agent 也会显示，单独排在「已归档」分区，右端取归档时间。内部 agent 不在列表中。workspace 名与颜色来自所选 daemon 的 workspace 列表，agent 列表通过长订阅实时更新；数据首次加载后缓存在应用内，再次打开立即渲染并后台刷新。需要 Paseo 0.13.0 及以上，不需要任何账号或额外配置。
