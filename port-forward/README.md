# Port forward plugin

在 Paseo 里管理 daemon 主机上的 TCP 端口转发与监听端口扫描。

- 侧边栏 **端口转发** surface：规则的启停/编辑/删除/打开，实时状态与流量统计；
  「服务器端口」标签扫描主机上监听中的端口，可一键建转发或直接打开。
- 规则持久化在宿主 settings，daemon 重启/插件重载后自动恢复。
- 全部逻辑在 daemon 主机执行（server 端 Node `net`），client 端只负责界面。

适用场景：把远程服务器上只绑定 `127.0.0.1` 的服务（如 `127.0.0.1:8080`）通过
`0.0.0.0:18080` 暴露给客户端访问；或在 Paseo daemon 就在本机时做常规的本地端口转发
（`127.0.0.1:8080 → target:8080`）。

详细说明见 [OVERVIEW.md](./OVERVIEW.md)。
